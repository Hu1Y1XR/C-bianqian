# C便签

> Windows 桌面便签 / 待办 / 购物清单 / 日历应用（本地版，数据不出电脑）

一个深色玻璃风格的桌面效率小工具：便签可以「贴到桌面」变成悬浮小窗，支持重复提醒、农历月视图日历、带价格统计的购物清单。

## ⚠️ 声明（请先读我）

- 本项目由 **AI 辅助开发**（GLM + ZCode 智能体）：使用者提出需求与反馈，AI 编写代码，并经多轮人工测试迭代而成
- 本项目**完全本地运行**：不联网、不上传、不收集任何数据，所有内容保存在本机 `%APPDATA%\C便签` 目录
- 代码仅供学习交流使用，**请勿用于商业用途**；使用本软件产生的任何问题由使用者自行承担
- 发布的 exe 为免安装绿色版，如对二进制有顾虑，可自行克隆源码运行或打包

## 功能一览

### 便签
- 深色玻璃主面板 + 桌面侧边栏，分类自定义（右键重命名/删除/拖拽排序）
- 行内快捷新增、富文本编辑器（加粗/下划线/删除线/列表/**清单模式逐行打勾**/插入图片）
- 右键菜单：完成 / 提醒 / 7 色 / 复制 / 移动 / **贴到桌面** / 删除
- 「贴到桌面」：便签变成独立悬浮小窗，可吸附屏幕四边

### 待办 & 购物清单
- 勾选完成、拖拽排序、删除已完成
- 购物模式：每行可填**价格（¥）**，双击打开详情（类型 / 渠道）
- 自动统计：待买 / 已买 / 合计金额实时计算

### 日历
- 月视图 / 周视图，农历 + 节气 + 节日
- 提醒自动落到日期格，双击日期直接记录
- 透明度调节、周起始日切换

### 提醒
- 单次 / 按天 / 按周 / 按月（可多选每月日期）/ 按年重复，支持截止日期与重要事项
- 到点弹系统通知（主进程调度，无需联网）

### 其他
- 托盘常驻、随软件启动、窗口折叠 / 隐藏 / 边缘吸附
- 全部数据 JSON 存储于本机，随开随用

## 下载使用

到 [Releases](../../releases) 页面下载 `C便签-win32-x64.zip`，解压后运行 **C便签.exe** 即可（免安装，Win10/11 x64）。

## 本地开发

```bash
npm install
npm start
```

依赖：Node.js ≥ 18。技术栈：Electron + 原生 HTML/CSS/JS + lunar-javascript（农历计算）。

## 目录结构

```
main.js            主进程（窗口/数据/提醒调度/托盘）
preload.js         渲染进程安全桥
src/panel/         主面板（便签/待办/日历/设置四视图）
src/sticky/        桌面便签小窗
src/editor/        大编辑器（重复提醒/附件/清单）
src/common/        公共样式与组件（菜单/下拉/清单逻辑）
```
